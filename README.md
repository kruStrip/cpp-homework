# C++: домашние работы

Домашние работы по C++ отдельными проектами Visual Studio: синтаксис, массивы и матрицы,
структуры, указатели, ООП.

**Стек:** C++ · Visual Studio

## Что внутри

- `car`, `car-and-truck` — классы и наследование
- `colors` — цветной вывод в консоль
- `pointers-01` … `pointers-04` — задания по указателям
- `structs-01` … `structs-03` — задания по структурам
- `bubble-sort`, `string-compare`, `sentence-count`, `primes` — сортировка, строки, простые числа
- `operator-overload`, `polymorphism` — перегрузка оператора и полиморфизм
- остальные папки — небольшие задачи: возраст, координаты, прогрессии, интеграл, корни, логарифм

## Запуск

Открыть `cpp-homework.sln` в Visual Studio и собрать нужный проект.
